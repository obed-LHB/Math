Formules utiles

Les principales formules à connaître.

Discriminant

Δ = b² − 4ac

Si Δ > 0

x₁ = (−b − √Δ) / 2a
x₂ = (−b + √Δ) / 2a

Si Δ = 0

x₀ = −b / 2a

Si Δ < 0

x₁ = (−b − i√|Δ|) / 2a
x₂ = (−b + i√|Δ|) / 2a
📚

Les trois cas du discriminant

Comment interpréter la valeur de Δ ?

Δ > 0

Deux solutions réelles

L'équation possède deux solutions réelles distinctes : x₁ et x₂.

Δ = 0

Une solution réelle

L'équation possède une solution réelle unique : x₀.

Δ < 0

Aucune solution réelle

L'équation ne possède aucune solution dans ℝ, mais possède deux solutions complexes.
